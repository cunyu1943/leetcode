# [15. 三数之和](https://leetcode.cn/problems/3sum/)



## 一、题目描述

给你一个整数数组 `nums`，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k`，同时还满足 `nums[i] + nums[j] + nums[k] == 0`。请你返回所有和为 `0` 且不重复的三元组。

**注意：**答案中不可以包含重复的三元组。



**示例 1：**

```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
```

**示例 2：**

```
输入：nums = [0,1,1]
输出：[]
```

**示例 3：**

```
输入：nums = [0,0,0]
输出：[[0,0,0]]
```

**提示：**

-   `3 <= nums.length <= 3000`
-   `-10^5 <= nums[i] <= 10^5`



## 二、解答方法

### 2.1 方法一：排序 + 双指针

1. **思路**

固定一个数，剩下两个数用双指针在有序数组中寻找，把三数之和问题转化为二数之和：

-   先将 `nums` 升序排序；
-   外层循环枚举 `i`（作为三元组最小数），若 `nums[i] > 0` 可提前结束（后面都为正，和不可能为 0）；
-   跳过重复的 `i` 去重；
-   内层用 `left = i+1`、`right = n-1` 双指针：`sum = nums[i] + nums[left] + nums[right]`，根据与 0 的大小移动指针；
-   找到等于 0 时记录结果，并同时跳过 `left`、`right` 两侧的重复值去重。

2. **代码实现**

::::: code-group

```java [Java]
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> res = new ArrayList<>();
        int n = nums.length;
        for (int i = 0; i < n - 2; i++) {
            if (nums[i] > 0) break;
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            int left = i + 1, right = n - 1;
            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];
                if (sum == 0) {
                    res.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    while (left < right && nums[left] == nums[left + 1]) left++;
                    while (left < right && nums[right] == nums[right - 1]) right--;
                    left++; right--;
                } else if (sum < 0) {
                    left++;
                } else {
                    right--;
                }
            }
        }
        return res;
    }
}
```

3. **复杂度分析**

- **时间复杂度**：`O(n²)`，排序 `O(n log n)`，外层 `n`、内层双指针 `O(n)`。
- **空间复杂度**：`O(log n) ~ O(n)`，排序递归栈，结果存储不计。

### 2.2 方法二：哈希表（枚举 + 两数之和）

1. **思路**

固定 `nums[i]`，在剩余部分用哈希表找 `-nums[i]`，即两数之和问题。需注意三元组整体去重，比双指针更难处理重复，一般不作首选。

2. **代码实现**

::::: code-group

```java [Java]
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        Set<List<Integer>> set = new HashSet<>();
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            Set<Integer> seen = new HashSet<>();
            for (int j = i + 1; j < n; j++) {
                int need = -(nums[i] + nums[j]);
                if (seen.contains(need)) {
                    int[] triplet = {nums[i], nums[j], need};
                    Arrays.sort(triplet);
                    set.add(Arrays.asList(triplet[0], triplet[1], triplet[2]));
                }
                seen.add(nums[j]);
            }
        }
        return new ArrayList<>(set);
    }
}
```

```python [Python]
class Solution:
    def threeSum(self, nums: List[int]) -> List[List[int]]:
        nums.sort()
        res = set()
        n = len(nums)
        for i in range(n):
            seen = set()
            for j in range(i + 1, n):
                need = -(nums[i] + nums[j])
                if need in seen:
                    res.add(tuple(sorted((nums[i], nums[j], need))))
                seen.add(nums[j])
        return [list(t) for t in res]
```

```go [Go]
func threeSum(nums []int) [][]int {
    sort.Ints(nums)
    res := [][]int{}
    seen := map[string]bool{}
    n := len(nums)
    for i := 0; i < n; i++ {
        m := map[int]bool{}
        for j := i + 1; j < n; j++ {
            need := -(nums[i] + nums[j])
            if m[need] {
                key := fmt.Sprintf("%d,%d,%d",
                    min3(nums[i], nums[j], need),
                    mid3(nums[i], nums[j], need),
                    max3(nums[i], nums[j], need))
                if !seen[key] {
                    seen[key] = true
                    res = append(res, []int{nums[i], nums[j], need})
                }
            }
            m[nums[j]] = true
        }
    }
    return res
}
```

```cpp [C++]
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        set<vector<int>> st;
        int n = nums.size();
        for (int i = 0; i < n; i++) {
            unordered_set<int> seen;
            for (int j = i + 1; j < n; j++) {
                int need = -(nums[i] + nums[j]);
                if (seen.count(need)) {
                    vector<int> t = {nums[i], nums[j], need};
                    sort(t.begin(), t.end());
                    st.insert(t);
                }
                seen.insert(nums[j]);
            }
        }
        return vector<vector<int>>(st.begin(), st.end());
    }
};
```

3. **复杂度分析**

- **时间复杂度**：`O(n²)`，枚举 `i` 后内层哈希查找 `O(1)`，但有排序与去重开销。
- **空间复杂度**：`O(n)`，哈希表与结果存储。

## 三、总结

两种方法对比：

| 方法 | 时间复杂度 | 空间复杂度 | 特点 |
| ---- | ---------- | ---------- | ---- |
| 排序 + 双指针 | `O(n²)` | `O(log n) ~ O(n)` | 空间紧凑，常为常数级 |
| 哈希表（枚举 + 两数之和） | `O(n²)` | `O(n)` | 查找/聚合高效 |
