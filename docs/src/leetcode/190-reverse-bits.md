# [190. 颠倒二进制位](https://leetcode.cn/problems/reverse-bits/)



## 一、题目描述

颠倒给定的 32 位无符号整数的二进制位。

**提示：**

-   请注意，在某些语言（如 Java）中，没有无符号整数类型。在这种情况下，输入和输出都将被指定为带符号整数类型，并且不应影响您的实现，因为无论整数是有符号的还是无符号的，其内部的二进制表示形式都是相同的。
-   在 Java 中，编译器使用 **二进制补码** 记法来表示有符号整数。因此，在 **示例 3** 中，输入表示有符号整数 `-3`，输出表示有符号整数 `-1073741825`。



**示例 1：**

```
输入：n = 00000010100101000001111010011100
输出：964176192 (00111001011110000010100101000000)
解释：输入的二进制串 00000010100101000001111010011100 表示无符号整数 43261596，
     因此返回 964176192，其二进制表示形式为 00111001011110000010100101000000。
```

**示例 2：**

```
输入：n = 11111111111111111111111111111101
输出：3221225471 (10111111111111111111111111111111)
解释：输入的二进制串 11111111111111111111111111111101 表示无符号整数 4294967293，
     因此返回 3221225471，其二进制表示形式为 10111111111111111111111111111111。
```

**提示：**

-   输入是一个长度为 `32` 的二进制字符串



**进阶：** 如果多次调用这个函数，你将如何优化它？



## 二、解答方法

### 2.1 方法一：逐位提取 + 移位

1. **思路**

循环 32 次：每次取 `n` 的最低位（`n & 1`），左移 `(31 - i)` 位后或到结果 `rev` 中；`n` 右移 1 位。最终得到反转位。

2. **代码实现**

:::::: code-group

```java [Java]
public class Solution {
    public int reverseBits(int n) {
        int rev = 0;
        for (int i = 0; i < 32; i++) {
            rev |= (n & 1) << (31 - i);
            n >>>= 1; // 无符号右移
        }
        return rev;
    }
}
```

3. **复杂度分析**

- **时间复杂度**：`O(1)`（固定 32 次）。

### 2.2 方法二：分治位反转（优化多次调用）

1. **思路**

若多次调用，可用「分治 + 掩码」一次性反转：每 2 位互换、每 4 位互换、每 8/16 位互换。利用魔法常数：

```
n = ((n >> 1) & 0x55555555) | ((n & 0x55555555) << 1);
n = ((n >> 2) & 0x33333333) | ((n & 0x33333333) << 2);
n = ((n >> 4) & 0x0F0F0F0F) | ((n & 0x0F0F0F0F) << 4);
n = ((n >> 8) & 0x00FF00FF) | ((n & 0x00FF00FF) << 8);
n = (n >> 16) | (n << 16);
```

2. **代码实现（Java）**

```java
public class Solution {
    public int reverseBits(int n) {
        n = ((n >>> 1) & 0x55555555) | ((n & 0x55555555) << 1);
        n = ((n >>> 2) & 0x33333333) | ((n & 0x33333333) << 2);
        n = ((n >>> 4) & 0x0F0F0F0F) | ((n & 0x0F0F0F0F) << 4);
        n = ((n >>> 8) & 0x00FF00FF) | ((n & 0x00FF00FF) << 8);
        n = (n >>> 16) | (n << 16);
        return n;
    }
}
```

3. **复杂度分析**

- 时间 `O(1)`，无循环，适合高频调用。

## 三、总结

逐位法是通用解法；分治位反转（5 个掩码）在多次调用时性能更优（无循环、纯位运算）。注意 Java/JS 使用 **无符号右移 `>>>`** 避免出现符号位问题。
