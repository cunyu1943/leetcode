# [193. 有效电话号码](https://leetcode.cn/problems/valid-phone-numbers/)



## 一、题目描述

给定一个包含电话号码列表（一行一个电话号码）的文本文件 `file.txt`，写一个 bash 脚本输出 **所有** 有效的电话号码。

你可以假设一个有效的电话号码必需是以下两种格式之一：

-   `xxx-xxx-xxxx`
-   `xxx xxx xxxx`

其中 `x` 表示一个数字（0-9）。

**示例：**

假设 `file.txt` 内容如下：

```
987-123-4567
123 456 7890
(123) 456-7890
```

你的脚本应当输出以下有效的电话号码：

```
987-123-4567
123 456 7890
```

**说明：** 本题是 LeetCode **Shell** 分类题，常用 `grep` 正则匹配两种格式。注意 `(123) 456-7890` 不符合本题定义的「有效」格式（带括号），不应输出。



## 二、解答方法

### 2.1 方法一：grep -E 正则

1. **思路**

用扩展正则 `-E` 匹配两种模式：`\d{3}-\d{3}-\d{4}` 或 `\d{3} \d{3} \d{4}`。用 `-P`（PCRE）可直接用 `\d{3}`，否则用 `[0-9]`。

2. **代码实现**

:::::: code-group

```bash [bash（GNU grep 支持 -P）]
grep -P '^(\d{3}-|\d{3} )\d{3}-\d{4}$' file.txt
```

```bash [bash（通用，[0-9] 写法）]
grep -E '^([0-9]{3}-|\[0-9]{3} )[0-9]{3}-[0-9]{4}$' file.txt
```

::::::

### 2.2 方法二：awk 匹配

1. **思路**

`awk` 配合 `~` 正则匹配整行。

2. **代码实现**

```bash
awk '/^([0-9]{3}-|\[0-9]{3} )[0-9]{3}-[0-9]{4}$/' file.txt
```

3. **复杂度分析**

- `grep` 流式扫描，`O(m)`，m 为文件行数。

## 三、总结

| 方法 | 优点 |
| ---- | ---- |
| `grep -E/-P` | 一行搞定，最常用 |
| `awk` | 可同时做字段处理 |

正则中 `^...$` 锚定整行，避免匹配到行内子串；`-P` 支持 `\d`，否则用 `[0-9]` 更通用。
