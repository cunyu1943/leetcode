# [18. 四数之和](https://leetcode.cn/problems/4sum/)



## 一、题目描述

给你一个由 `n` 个整数组成的数组 `nums` 和一个目标值 `target`。请你找出并返回满足下述全部条件且 **不重复** 的四元组 `[nums[a], nums[b], nums[c], nums[d]]`：

-   `0 <= a, b, c, d < n`
-   `a`、`b`、`c` 和 `d` **互不相同**
-   `nums[a] + nums[b] + nums[c] + nums[d] == target`

你可以按 **任意顺序** 返回答案。



**示例 1：**

```
输入：nums = [1,0,-1,0,-2,2], target = 0
输出：[[-2,-1,1,2],[-2,0,0,2],[-1,0,0,1]]
```

**示例 2：**

```
输入：nums = [2,2,2,2,2], target = 8
输出：[[2,2,2,2]]
```

**提示：**

-   `1 <= nums.length <= 200`
-   `-10^9 <= nums[i] <= 10^9`
-   `-10^9 <= target <= 10^9`



## 二、解答方法

### 2.1 方法一：排序 + 双层双指针

1. **思路**

在三数之和基础上再套一层循环：排序后，先枚举 `i`，再枚举 `j`，剩下两个数用双指针在 `[j+1, n-1]` 区间内寻找 `target - nums[i] - nums[j]`。

-   两层枚举均做去重（跳过相邻的相同值）；
-   可加剪枝：若 `nums[i] + nums[i+1] + nums[i+2] + nums[i+3] > target` 则 `i` 之后更大，直接 `break`；若 `nums[i] + nums[n-3] + nums[n-2] + nums[n-1] < target` 则 `i` 太小，直接 `continue`；
-   找到四元组后，对 `left`、`right` 两侧去重。

2. **代码实现**

::::: code-group

```java [Java]
class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {
        Arrays.sort(nums);
        List<List<Integer>> res = new ArrayList<>();
        int n = nums.length;
        for (int i = 0; i < n - 3; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            for (int j = i + 1; j < n - 2; j++) {
                if (j > i + 1 && nums[j] == nums[j - 1]) continue;
                int left = j + 1, right = n - 1;
                while (left < right) {
                    long sum = (long) nums[i] + nums[j] + nums[left] + nums[right];
                    if (sum == target) {
                        res.add(Arrays.asList(nums[i], nums[j], nums[left], nums[right]));
                        while (left < right && nums[left] == nums[left + 1]) left++;
                        while (left < right && nums[right] == nums[right - 1]) right--;
                        left++; right--;
                    } else if (sum < target) {
                        left++;
                    } else {
                        right--;
                    }
                }
            }
        }
        return res;
    }
}
```

3. **复杂度分析**

- **时间复杂度**：`O(n³)`，两层循环 `O(n²)` 配合内层双指针 `O(n)`。

### 2.2 方法二：哈希表（两数之和 + 两数之和）

1. **思路**

将所有两两之和存入哈希表（记录值及其下标组合），再枚举另外两数，查表寻找 `target - 两数之和`，并校验四下标互不相同、整体去重。实现复杂、去重繁琐，一般不作为首选。

2. **代码实现**

::::: code-group

```java [Java]
class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {
        Arrays.sort(nums);
        Set<List<Integer>> set = new HashSet<>();
        int n = nums.length;
        Map<Long, List<int[]>> map = new HashMap<>();
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                long sum = (long) nums[i] + nums[j];
                map.computeIfAbsent(sum, k -> new ArrayList<>()).add(new int[]{i, j});
            }
        }
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                long need = (long) target - nums[i] - nums[j];
                if (map.containsKey(need)) {
                    for (int[] pair : map.get(need)) {
                        int a = pair[0], b = pair[1];
                        if (a > j) {
                            int[] t = {nums[i], nums[j], nums[a], nums[b]};
                            Arrays.sort(t);
                            set.add(Arrays.asList(t[0], t[1], t[2], t[3]));
                        }
                    }
                }
            }
        }
        return new ArrayList<>(set);
    }
}
```

class Solution:
    def fourSum(self, nums: List[int], target: int) -> List[List[int]]:
        from collections import defaultdict
        nums.sort()
        res = set()
        n = len(nums)
        mp = defaultdict(list)
        for i in range(n):
            for j in range(i + 1, n):
                mp[nums[i] + nums[j]].append((i, j))
        for i in range(n):
            for j in range(i + 1, n):
                need = target - nums[i] - nums[j]
                if need in mp:
                    for a, b in mp[need]:
                        if a > j:
                            t = tuple(sorted((nums[i], nums[j], nums[a], nums[b])))
                            res.add(t)
        return [list(t) for t in res]

class Solution {
public:
    vector<vector<int>> fourSum(vector<int>& nums, int target) {
        sort(nums.begin(), nums.end());
        set<vector<int>> st;
        int n = nums.size();
        unordered_map<long long, vector<pair<int, int>>> map;
        for (int i = 0; i < n; i++)
            for (int j = i + 1; j < n; j++)
                map[(long long)nums[i] + nums[j]].push_back({i, j});
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                long long need = (long long)target - nums[i] - nums[j];
                if (map.count(need)) {
                    for (auto& p : map[need]) {
                        int a = p.first, b = p.second;
                        if (a > j) {
                            vector<int> t = {nums[i], nums[j], nums[a], nums[b]};
                            sort(t.begin(), t.end());
                            st.insert(t);
                        }
                    }
                }
            }
        }
        return vector<vector<int>>(st.begin(), st.end());
    }
};

/**
 * @param {number[]} nums
 * @param {number} target
 * @return {number[][]}

var fourSum = function (nums, target) {
    nums.sort((a, b) => a - b);
    const set = new Set();
    const res = [];
    const n = nums.length;
    const map = new Map();
    for (let i = 0; i < n; i++) {
        for (let j = i + 1; j < n; j++) {
            const sum = nums[i] + nums[j];
            if (!map.has(sum)) map.set(sum, []);
            map.get(sum).push([i, j]);
        }
    }
    for (let i = 0; i < n; i++) {
        for (let j = i + 1; j < n; j++) {
            const need = target - nums[i] - nums[j];
            if (map.has(need)) {
                for (const [a, b] of map.get(need)) {
                    if (a > j) {
                        const t = [nums[i], nums[j], nums[a], nums[b]].sort((x, y) => x - y);
                        const key = t.join(',');
                        if (!set.has(key)) {
                            set.add(key);
                            res.push(t);
                        }
                    }
                }
            }
        }
    }
    return res;
};

- **时间复杂度**：`O(n²)`，建表 `O(n²)` + 枚举 `O(n²)`，哈希查找 `O(1)`。

## 三、总结

两种方法对比：

| 方法 | 时间复杂度 | 空间复杂度 | 特点 |
| ---- | ---------- | ---------- | ---- |
| 排序 + 双层双指针 | `O(n³)` | `O(log n) ~ O(n)` | 空间紧凑，常为常数级 |
| 哈希表（两数之和 + 两数之和） | `O(n²)` | `O(n²)` | 查找/聚合高效 |
